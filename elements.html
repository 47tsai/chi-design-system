CHI DESIGN SYSTEM / DOCUMENTATION

介面元件，有章可循。

這裡不是網站模板，而是 Chi 共用介面的工作手冊。從色彩、字體與間距，到可重用元件和常見頁面模式，展示每個選擇該如何服務內容與操作。

探索元件 閱讀 DESIGN.md

THE PRINCIPLE

清楚的層級，
比更多裝飾重要。

先用排版、留白與語意建立秩序。只有在需要時，才加入邊框、表面層級與陰影。

01 / FOUNDATIONS

基礎規格

用一致的語意 token 管理色彩、字體、間距與表面。實際數值以 tokens.css 為準，避免各頁面自行長出一套規則。

A

色彩角色

LIGHT / DARK

色彩先表達用途，再表達裝飾。切換主題時，元件只需讀取同一個語意 token。

Surface--chi-color-surface

Accent--chi-color-accent
Blue accent--chi-color-accent-blue
Border--chi-color-border
B

文字層級

TYPE SCALE

--chi-text-md

--chi-text-sm

02 / COMPONENTS

元件圖鑑

每個元件都要有清楚用途、可辨識的狀態與合理的鍵盤行為。可以搜尋名稱、用途或英文關鍵字，快速找到需要的範例。

12 個範例

顯示全部範例。

C01

按鈕與操作

Action

主要操作清楚突出，次要操作降低視覺重量；危險操作需與一般流程區隔。

<button class="chi-button chi-button--primary">
  儲存變更
</button>
C02

輸入欄位

Form

欄位標籤、提示與錯誤訊息都應直接對應輸入內容，不能只用顏色傳達錯誤。

用於帳號通知，不會公開顯示。

請檢查這個欄位的內容。

<label class="chi-label" for="email">
  電子郵件
</label>
<input class="chi-input" id="email" type="email">
C03

開關與設定列

Settings

開關適用於切換後立即生效的布林設定；需要提交的設定應使用明確的表單流程。

<label class="preview-setting-row">
  <span>郵件通知</span>
  <input class="chi-switch" type="checkbox">
</label>
C04

頁籤

Navigation

頁籤切換同一層級的相關內容，選取狀態要可見，也要能用鍵盤切換。

總覽內容顯示在這裡。分頁只切換同一層級的內容。
C05

狀態標籤

Status

標籤用來快速辨識狀態，不是裝飾。保持文字簡短，避免同一畫面出現太多高彩度徽章。

已完成 等待處理 需要注意 草稿
C06

提示訊息

Feedback

需要持續閱讀的錯誤或提醒應留在內容中；不要把重要資訊只放在短暫消失的 Toast。

已儲存變更已在此示範介面中完成。
請留意離開前請確認尚未完成的內容。
C07

Toast 通知

Transient

適合非阻斷性的操作結果。此範例只在頁面上顯示示範訊息，不會呼叫 API 或保存資料。

C08

資料表格

Data

欄位名稱保持清楚，狀態與操作放在一致的位置；窄螢幕時應有替代呈現方式。

項目狀態更新時間
設計規格已同步剛剛
元件清單待檢查今天
主題設定草稿昨天
C09

清單與資料列

List

把名稱、輔助說明、狀態與操作整理在同一閱讀路徑，適合設定、服務綁定與最近活動。

DS設計系統共用樣式與元件規範已連結
UI元件圖鑑HTML / CSS 示範頁文件
C10

空狀態

Empty

明確說明目前沒有什麼，並提供合理的下一步。不要只留下空白或一張沒有解釋的插圖。

目前沒有符合的項目

調整篩選條件，或清除搜尋後再試一次。

C11

載入與進度

Loading

載入時保留內容的大致尺寸，降低版面跳動。動態效果需尊重減少動態的系統偏好。

同步進度 68%
C12

選單與浮層原則

Overlay

浮層需要清楚的觸發器、展開狀態與關閉方式。不要讓重要功能只能靠 hover 使用。

選單操作僅更新此處的示範文字。

沒有找到符合條件的範例，試試其他關鍵字或切回「全部」。

03 / PAGE PATTERNS

版型模式

設計系統提供組合方式，不是要求所有網站長得一樣。依照使用者的任務選擇資訊架構，再套用共同的視覺語言。

公開入口與品牌介紹

04 / IMPLEMENTATION

把規格帶進專案

先讀設計契約，再選擇共用樣式。正式產品應重用 tokens 與元件，不應載入本頁專用的 elements.css。

  1. 01
    載入共用樣式

    tokens.css → components.css → navigation.css

  2. 02
    使用語意 token 與元件

    優先選用既有的 chi-button、chi-input、chi-panel 等元件。

  3. 03
    驗證兩種主題與響應式

    檢查焦點、錯誤、停用、載入、空狀態與窄螢幕行為。
