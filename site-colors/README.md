# Website Color Registry

集中記錄 Chi 生態系各網站的品牌色與介面配色，避免不同專案的顏色設定互相混淆。

## 原則

- **品牌主藍：** `#4a88fc`，作為 Chi 生態系的共同識別色。
- **不強制所有網站使用同一套配色或版型。** 各網站可依用途設定自己的輔助色、背景色與表面色。
- 藍色可作為主要操作、連結、焦點與選取狀態；實際使用比例由各產品決定。
- 本目錄是設計規範與紀錄，不會自動修改其他網站的 CSS。
- 更新某個網站的顏色時，請同步更新 `sites.yml`，並視需要補充該網站的獨立說明檔。

## 檔案

- `sites.yml`：各網站的顏色登記表。
- 可按需要新增 `<網站名稱>.md`，記錄更完整的色票與使用方式。

## 顏色欄位

- `brand`：網站品牌／主要識別色。
- `accent`：輔助強調色；沒有特別需求時可留空。
- `page`：頁面背景色。
- `surface`：卡片、面板等表面色。
- `text`：主要文字色。
- `notes`：使用原則或尚待確認的事項。

尚未確認的顏色應標示為 `TBD`，不要把推測值當成已定案規格。
